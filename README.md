# CodeAlpha_HandwrittenRecognition

## Handwritten Digit Recognition using CNN

This project is developed as part of the Machine Learning Internship at CodeAlpha.

The objective of this project is to recognize handwritten digits using Deep Learning and Convolutional Neural Networks (CNN).

---

# Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Google Colab

---

# Dataset

Dataset Used: MNIST Handwritten Digits Dataset

The dataset contains thousands of handwritten digit images from 0 to 9.

---

# Deep Learning Model

The project uses Convolutional Neural Networks (CNN) for image classification.

Layers Used:
- Convolution Layer
- Max Pooling Layer
- Flatten Layer
- Dense Layer

---

# Project Workflow

1. Import Dataset
2. Data Preprocessing
3. Normalize Images
4. Build CNN Model
5. Train Model
6. Evaluate Accuracy
7. Predict Digits

---

# Results

The CNN model achieved high accuracy in handwritten digit recognition.
